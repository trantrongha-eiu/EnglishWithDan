# ⚔️ Đấu trường — "Nhìn hình đoán từ" picture words.
# Pictures = Microsoft Fluent Emoji 3D (MIT licence,
# github.com/microsoft/fluentui-emoji). build.js uploads each picture to R2
# and writes ../../data/vocabBattle/pictureWords.json.
#
# "## <set id> | <set title>" starts a set (wrong options come from the same
# set). Each line: <Fluent Emoji folder name> | <English word> | <nghĩa>
# Rules used when picking: the picture must show THAT word and nothing else
# in its set could be the answer too (one of bus/minibus, ship/ferry, …).
# "~ a, b, c" = words of the set that look alike: never offered together
# (asked "rain", "cloud" is not a wrong option).
